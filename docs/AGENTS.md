# Portuguese Survivor Agent Guide

## Purpose

Guide every AI agent and developer working on the project.

## First Rule

Read [docs/PRODUCT_BIBLE.md](PRODUCT_BIBLE.md) first before making changes.

## Non Negotiables

- Never violate the product non-negotiables.
- Never hardcode lesson content.
- Keep learning content JSON-driven where possible.
- Use reusable widgets.
- Keep UI language in the child’s native language.
- Portuguese appears only in learning content.
- Use European Portuguese only.
- Every feature must improve real-life adaptation.
- Never punish mistakes; offer hints and encouragement instead.

## Development Principles

- Prefer simple, reusable, well-named components.
- Keep the experience emotionally safe and encouraging.
- Favor clarity over complexity.
- Preserve the mission-driven structure.
- Maintain accessibility and child-friendly UX.
