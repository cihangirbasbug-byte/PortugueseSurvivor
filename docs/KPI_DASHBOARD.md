# Portuguese Survivor — KPI Dashboard

## 1. Purpose

This document defines the key performance indicators used to monitor Portuguese Survivor.

The KPI system exists to answer:

- Is the product progressing?
- Are players using the product?
- Are players learning?
- Is the application technically stable?
- Is content production progressing?
- Is the team working on the highest-value objectives?

KPIs must support decisions.

They must not become vanity metrics.

---

# 2. KPI Categories

Portuguese Survivor KPIs are divided into seven categories:

1. Product
2. Gameplay
3. Learning
4. Engagement
5. Technical Quality
6. Production
7. Business
