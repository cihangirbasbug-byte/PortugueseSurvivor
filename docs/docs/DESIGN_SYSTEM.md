# Portuguese Survivor

# Design System

Version 1.0

---

# Design Philosophy

Portuguese Survivor is not a textbook.

It is not an educational website.

It is an adventure game where language learning happens naturally.

Every screen should feel:

• warm
• playful
• friendly
• premium
• modern

---

# Emotional Goal

The player should smile.

The player should never feel stressed.

The player should always want to continue.
