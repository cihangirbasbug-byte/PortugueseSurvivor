# AGENT REPORTING STANDARD

## Portuguese Survivor — AI Agent Reporting Standard

**Document Type:** AI Reporting Standard  
**Project:** Portuguese Survivor  
**Version:** 1.0  
**Status:** Active  
**Authority:** CEO / Project Director

---

# 1. PURPOSE

The Agent Reporting Standard defines how Portuguese Survivor AI agents communicate task progress, results, blockers, risks, decisions, and next actions.

The purpose is to ensure that every important piece of work can be understood without requiring the reader to reconstruct the entire conversation history.

The fundamental principle is:

> **Every significant task must leave a clear operational record.**

---

# 2. REPORTING PRINCIPLES

Agent reports must be:

- clear
- concise
- factual
- structured
- actionable
- evidence-based
- traceable

Agents must avoid:

- unnecessary narrative
- vague statements
- unsupported claims
- hidden assumptions
- reporting work as complete before validation
- claiming tests were performed when they were not
- hiding blockers or risks

---
