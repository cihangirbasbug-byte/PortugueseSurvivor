# 1. PURPOSE

The Escalation Protocol defines when an AI agent must stop making an independent decision and transfer the matter to a higher level of authority.

The purpose is to prevent:

- incorrect autonomous decisions
- conflicting project decisions
- silent scope changes
- unsafe technical changes
- educational inaccuracies
- European Portuguese errors
- unnecessary rework
- release risks
- strategic drift
- undocumented decisions

The fundamental principle is:

> **Agents should be autonomous within their authority and escalate outside it.**
