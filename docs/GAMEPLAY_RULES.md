# Portuguese Survivor Gameplay Rules

Version: 1.0

---

# Philosophy

Portuguese Survivor is not a vocabulary application.

It is a story-driven survival game where language learning happens naturally.

The player should always feel progress.

Never punishment.

Never frustration.

---

---

# XP System

Every mission grants XP.

Typical reward

20 XP

Perfect completion

25 XP

Bonus missions

30 XP

XP is never removed.

---

# Courage System

Courage represents confidence.

Correct answers increase Courage.

Hints do not decrease Courage.

Repeated mistakes reduce only Heart, not Courage.

---

# Heart System

Player starts with

5 Hearts

Wrong answer

−1 Heart

Correct answer

No Heart loss

Heart regeneration

One every 30 minutes

---

# Hint System

Hints are always positive.

Hints never reveal the complete answer immediately.

Hints encourage another attempt.

---

# Quiz Rules

Immediate feedback.

Correct

Celebrate.

Incorrect

Explain.

Retry.

Never shame the learner.

---

# Badge System

Each mission awards one badge.

Badges represent real-world achievements.

Examples

Coffee Survivor

Metro Hero

Market Explorer

Portuguese Listener

---

# Celebration

Mission Complete always includes

XP

Badge

Positive animation

Encouragement

Continue button

---

# Daily Streak

Learning every day builds a streak.

Missing one day breaks the streak.

Long streaks unlock cosmetic rewards only.

Never lock educational content.

---

# Unlock Rules

Player must finish Mission N

before Mission N+1.

Future chapters remain locked.

---

# Difficulty

Difficulty increases gradually.

Never introduce more than

5 new words

in one lesson.

---

# Review

Old words return automatically.

Review frequency adapts to learner performance.

---

# Failure

Failure is temporary.

Player always receives encouragement.

No Game Over.

No punishment screen.

# Character Rules

# Educational Rule

Every interaction must teach.

Every reward must motivate.

# Golden Rule

Learning follows naturally.
