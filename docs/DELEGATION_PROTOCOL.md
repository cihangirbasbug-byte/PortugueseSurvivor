# 1. PURPOSE

The Delegation Protocol defines how work is transferred from the CEO to the Project Director and from the Project Director to specialist agents.

The purpose is to ensure that:

- every task has a clear owner
- every task has a clear objective
- responsibilities are not duplicated
- agents do not work outside their authority
- dependencies are identified
- required reviews are known in advance
- important decisions are escalated correctly
- work can be tracked from request to completion

The fundamental delegation principle is:

> **Delegate responsibility, not ambiguity.**
