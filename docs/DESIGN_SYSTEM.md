# Portuguese Survivor Design System

Version: 1.0

---

# Design Philosophy

Portuguese Survivor must always feel

Warm

Friendly

Playful

Calm

Optimistic

Educational

Never cold.

Never corporate.

Never aggressive.

---

# Visual Identity

Style

Modern Illustration

Soft Shapes

Rounded Corners

Large Touch Areas

Comfortable Reading

# Animations

Fast

Smooth

Meaningful

# Pico

Pico is the emotional guide.

Pico celebrates.

Pico encourages.

Pico never criticizes.

---

# Sofia

Teacher Sofia teaches.

She is calm.

Patient.

Positive.

Professional.

---

# Celebration

Always positive.

Small particle effects.

Short animations.

Reward first.

Continue second.

---

# Audio Feedback

Correct

Happy

Soft

Incorrect

Gentle

Helpful

Never punish the learner.

---

# Haptic Feedback

Correct answer

Light Impact

Mission Complete

Medium Impact

Errors

Selection only

---

# Accessibility

High contrast

Large touch targets

Screen reader support

Reduce Motion support

Readable fonts

---

# UX Rules

One primary action per screen.

Never overwhelm users.

Never hide important actions.

Every interaction should feel rewarding.

---

# Golden Rule

Beautiful interfaces teach better.

Learning experience always comes before visual complexity.
