# Portuguese Survivor

## Project

Portuguese language learning application (European Portuguese).

## Technology Stack

* Flutter 3.x
* Dart
* Riverpod
* GoRouter
* SQLite
* Firebase

## Architecture

* Clean Architecture
* Repository Pattern
* SOLID Principles

## Coding Standards

Always:

* Use null-safe Dart.
* Prefer const constructors.
* Keep widgets small and reusable.
* Avoid duplicated code.
* Write clean, readable code.
* Add comments where appropriate.
* Create unit tests for business logic.

## Git

Use feature branches.

Commit format:

* feat:
* fix:
* docs:
* refactor:
* test:

## Goal

Build a production-ready Flutter application for Android and iOS.
